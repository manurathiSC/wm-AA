# T02 — EMA-Filtered SELL Strategy Backtest

## 1. Idea

The existing AA overlay (SCMO_0042) switches the entire portfolio to a
defensive sleeve (gold + cash) whenever the three-index supertrend regime
signals SELL. This is a binary, all-or-nothing decision.

T02 tests a refinement: during SELL regime weeks, instead of going fully
defensive, **keep the stocks whose close is above their 50-day exponential
moving average** at their original rebalance weights, and allocate only the
excluded stocks' weight to GOLDBEES. During BUY regime weeks, hold the full
parent basket unchanged.

The hypothesis is that stocks above their 50-day EMA are in relative strength
and may continue to outperform gold even during a regime-level SELL — so
keeping them selectively could improve returns without sacrificing too much
downside protection.

### Comparison benchmarks

| ID | Name | Behaviour |
|----|------|-----------|
| **SCMO_0003** | Growth at a Fair Price (parent) | Always holds the full equity basket. No regime overlay. |
| **SCMO_0042** | AA overlay | BUY regime = full equity. SELL regime = 100% defensive (gold/cash). |
| **T02 strategy** | EMA-filtered SELL | BUY regime = full equity. SELL regime = above-EMA stocks + gold for the rest. |


## 2. Strategy Rules

1. Each week, check the regime state (BUY / SELL) from the three-index
   supertrend. The regime is pre-computed in `Wm-SellRegRes` and embedded in
   the weekly holdings table as the `portfolio` column.

2. If **BUY**: target weights = parent basket weights from the most recent
   rebalance. 100% equity. No gold.

3. If **SELL**:
   - For each stock in the basket, look up `above_ema50` on the week's last
     trading session (the `date` column, not the Friday label `week_end`).
   - **Keep** stocks where `above_ema50 == 1` (close > 50-day EMA), at their
     original rebalance weights.
   - **Exclude** stocks where `above_ema50 == 0` (close <= 50-day EMA) or
     where EMA data is missing (`NaN`). Their combined weight goes to GOLDBEES.
   - Target = {kept stocks at original weights} + {GOLD at residual weight}.

4. Compute weekly returns from the target portfolio:
   `portfolio_return = sum(weight_i * (close_{t+1,i} / close_{t,i} - 1))`
   for all positions (stocks and GOLD).

5. Compound into a NAV series starting at 100.

6. No transaction costs in this first pass.

### 3.2 50-Day EMA Signals (per-stock, daily)

**Path:** `SELLHOLD/outputs/stocks_eikon_ema/<TICKER>.csv` (169 files)
**Generated by:** `SELLHOLD/build_eikon_ema.py`

| Column | Type | Description |
|--------|------|-------------|
| `date` | date (YYYY-MM-DD) | Trading day |
| `open` | float | Open price |
| `high` | float | High price |
| `low` | float | Low price |
| `close` | float | Close price |
| `ema50` | float | 50-day exponential moving average |
| `above_ema50` | string | `"True"` if close > ema50, `"False"` otherwise. Equal is NOT above. |

**EMA computation:**
- Period N = 50
- Multiplier k = 2 / (N + 1) = 2/51
- EMA_0 = simple moving average of first 50 closes
- EMA_t = close_t * k + EMA_{t-1} * (1 - k)
- `above_ema50 = close > ema50` (strict inequality; equal is not above)

**Join key:** T02 joins on `(ticker, date)` where `date` is the actual last
trading day of the week from the holdings table (the `date` column, not the
`week_end` Friday label). This matters when Friday is a holiday and the week
ends on Thursday.

## 4. Methodology

### 4.1 Price Lookup

For each stock, T02 loads daily closes from
`SELLHOLD/outputs/stocks_eikon/<TICKER>.csv`. For GOLDBEES, from
`SELLHOLD/outputs/gold.csv`. All prices are keyed by `pd.Timestamp`.

If a stock has no close on the exact weekly date, the script falls back to
the most recent close within the prior 7 calendar days (forward-fill).

### 4.2 EMA Signal Loading

T02 reads `above_ema50` from each file in
`SELLHOLD/outputs/stocks_eikon_ema/`. The `above_ema50` column is stored as
a string (`"True"` / `"False"`) and mapped to 1 / 0. Files with `NaN` in
`above_ema50` are dropped. Result: `{ticker: {date: 1_or_0}}`.

### 4.3 Weekly Return Computation

For week t (with target weights set at `date_t`):
```
return_week_t = sum over all positions i:
    weight_i * (close(ticker_i, date_{t+1}) / close(ticker_i, date_t) - 1)
```

Where positions include both kept stocks and GOLD (if any weight allocated).

NAV compounds: `NAV_{t+1} = NAV_t * (1 + return_week_t)`.

### 4.4 Benchmark Snapping

Benchmark NAVs are daily; the strategy is weekly. For each strategy weekly
date, the script finds the benchmark value on that date or the most recent
prior trading day (forward-fill). Dates beyond the benchmark's last data point
return NaN (no extrapolation).

### 4.5 Performance Metrics

| Metric | Formula |
|--------|---------|
| CAGR | `(NAV_end / NAV_start) ^ (1 / years) - 1` |
| Max drawdown | `min((NAV - peak) / peak)` over the series |
| Volatility | `std(weekly_returns) * sqrt(52)` (annualized) |
| Sharpe | `(CAGR - 0.06) / volatility` (6% risk-free for INR) |
| Calmar | `CAGR / |max_drawdown|` |

Returns are point-to-point simple: `end / start - 1` (never log).

## 7. Results

Run date: 2026-11-05.
Period: 2021-10-29 to 2026-10-30 (262 weeks: 124 BUY, 138 SELL).
No transaction costs.

### 7.1 Summary

During SELL weeks, the strategy kept an average of 4.6 stocks (out of ~11
held) and allocated 60.7% of portfolio weight to GOLDBEES.

### 7.2 Performance Comparison

| Series | NAV | CAGR | Total Return | Max DD | Volatility | Sharpe | Calmar |
|--------|-----|------|--------------|--------|------------|--------|--------|
| **EMA Strategy** | 247.6 | 19.9% | 147.6% | -18.6% | 16.1% | 0.86 | 1.07 |
| SCMO_0003 (Parent) | 186.6 | 13.4% | 86.6% | -29.0% | 21.4% | 0.34 | 0.46 |
| SCMO_0042 (AA) | 255.5 | 21.6% | 155.5% | -19.3% | 15.9% | 0.98 | 1.12 |

Note: SCMO_0003 data extends to 2026-10-22; SCMO_0042 data extends to
2026-08-21. Strategy NAV extends to 2026-10-30.

### 7.3 Interpretation

- The EMA strategy outperforms the pure equity parent (SCMO_0003) by ~6.5pp
  CAGR with ~10pp less drawdown and substantially better risk-adjusted returns
  (Sharpe 0.86 vs 0.34).

- The EMA strategy slightly lags the full AA overlay (SCMO_0042) on both CAGR
  (19.9% vs 21.6%) and Sharpe (0.86 vs 0.98). The binary switch to 100%
  gold during SELL has been more protective over this period.

- During SELL weeks, 60.7% of weight went to gold on average, meaning the
  strategy runs about 39% equity during SELL vs. 0% for SCMO_0042 and 100%
  for SCMO_0003. The remaining equity exposure (above-EMA stocks) has not
  added enough return to overcome the defensive benefit of full gold.

### 7.4 Next Steps

- Add transaction costs (20.8 bps round trip) to test sensitivity.
- Null analysis: circular signal shift on the EMA flag to measure whether
  the above/below EMA classification is better than random.
- Test variants: different EMA periods (20, 100, 200), or combining EMA
  with other indicators (200-SMA, SuperTrend).
- Extend to W1 window (2015-2021) if parent holdings data is available.
