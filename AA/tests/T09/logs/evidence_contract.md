## Names

- **Books:** `SCMO_0003`, `SCMO_0007`, `SCMO_0010`, `SCMO_0029` (the proxy books; the names only label the four band mixes of `T09.md` §3). **Windows:** `full` (T0 2011-11-25 → 2019-01-02), `r3` (T0 = the first session on or after 2012-01-02, → 2019-01-02). **Cash:** `lbes` (headline), `liq` (the desk's LIQUIDCASE file as-of, R2; equals LBES to 1.6e-10 in daily return in this window). **Costs:** 0, 20.8, 50 bps.
- **State arrays:** in-or-out `s` (1 = IN/proxy, 0 = OUT); gold `g` (1 = BUY, 0 = SELL); sleeve gold weight `gw` = 0.8 if g = 1 else 0.2 (`fixed50` mode: 0.5 always).
- **Null families:** `F1` = in-or-out N4.10 + real gold; `F2` = in-or-out N4.9 + real gold; `F3` = real in-or-out + gold N4.10-g; `F4` = real in-or-out + gold N4.9-g; `F5` = F1's in-or-out draw + F3's gold draw (same id). Seeds: N4.9 `default_rng([12, 3, id])`, N4.10 `[12, 6, id]`, N4.9-g `[12, 11, 3, id]`, N4.10-g `[12, 11, 6, id]`, id = 0..N-1 (N = 2000). Bounds per state of each series: `lo = min(2, shortest spell of the state)`, `hi = longest spell of the state` (in = state 1, out = state 0; gold BUY = state 1). Full window: in/out in [1, 32], out [2, 35]; gold BUY [2, 36], SELL [2, 27] (the numbers of `logs/step_1_spell_counts.json`, asserted by the engine). The four books have identical decision and gold series and **share** the draws; the engine generates the states once and stores them under every book's key.
- **`run` column values (stats.csv `kind`, trades.csv `run`, daily_nav.csv `run`):** `strategy` (the rule, timed sleeve), `strategy_fixed50` (the rule with the 50/50 sleeve: Part A's rule), `hold_proxy` (always IN, quarterly resets), `constant_mix` (50/50 non-proxy share), `constant_mix_timed`, `sleeve_only` (100% sleeve 50/50), `sleeve_only_timed`, `index_Nifty100`, `index_MC100`, `index_SC100` (one index held, weight 1, no resets), `strategy_r7a_proxy_fill_at_close` (R7a), `strategy_r7b_gold_weight_50_before_2014-07-01` (R7b). Comparators, R7 and `index_*` exist for the full-window LBES cell only (R7 at 20.8 only); every other cell (`full`/`liq`, `r3`/`lbes`) carries `strategy` and `strategy_fixed50` at 20.8.
- **Trade `kind` values:** `switch_in`, `switch_out`, `sleeve_rebalance` (OUT on both sides, g changed), `quarterly_reset` (IN only), `mix_rebalance` (constant mixes). `e_after` = proxy share after the trade; `gw_after` = the sleeve's gold weight target (0.8/0.2/0.5; empty for `hold_proxy` and `index_*`; on a `switch_in` row it is that decision's weight and irrelevant).

## Engine behaviour the verifier and the scripts must match (`T09.md` §3 steps 1–11)

1. Calendar = D26's dates from T0 to END; every session has a bar in all three D25 files (asserted). The Smallcap 100 price file is parsed from T0 only (text filter), its Master rows from T0 only. Index fill = OHLC4 of the D25 row, valuation = close.
2. Decisions: T0, then the last session of each ISO week; IN iff the latest Master row on or before the date is BUY in all three indices; `g` from `Master_MAUc1.xlsx` (D24b) the same way. The decision at END (2019-01-02) is made, not traded; a quarterly reset on END (it opens a quarter) **is** traded.
3. Initial position at T0's close, free: IN = units `w_i / close_i` (NAV 1); OUT = `gw` GOLDBEES and `1 − gw` cash of NAV 1 (`gw` 0.8 or 0.2 from T0's `g`; 0.5 for `fixed50`).
4. A decision trade exists on the next session iff `e` changed or (`e` = 0 and `gw` changed). Trade arithmetic (T06/T08, unchanged): V at the fill prices; targets `e·V·w_i`, `(1−e)·gw·V`, `(1−e)·(1−gw)·V`; `traded = Σ|target − held|`; `cost = ow × traded`, `ow = cost_bps/2/1e4`; every target scaled by `(V − cost)/V`.
5. Quarterly reset: a session `t > 0` in Jan/Apr/Jul/Oct whose previous session is in another month; it trades iff the book holds the proxy at the start of the session and no decision trade falls on it; same trade arithmetic with `e = 1`. None in `constant_mix*` or `index_*`; `hold_proxy` resets at every quarter start (29 on the full window).
6. GOLDBEES leg: close = D09b before 2014-07-01 chained with D09; fill = D09b's OHLC4 before 2014-07-01, T03's de-spike afterwards (D24b daily range; raw OHLC4 on the 3 sessions without an MCX bar: 2014-10-23, 2015-01-01, 2015-11-11); the session 2016-10-30 (an NSE session) has no gold bar and uses the previous close and fill. R7a: fills in the proxy period at the proxy close. R7b: decisions dated before 2014-07-01 use gold weight 0.5.
7. Cash: LBES level as-of on sessions (R2: liquidEtfFinal as-of).
8. Statistics, percentile, p-value, MDE: `T09.md` §2–§3.
