## What each script does

- **`analyse.py`** reads only `evidence/<run>/{w1,w2}/` (`--run headline` default; `--evidence DIR` for any folder holding `w1/`, `w2/`; `--books` restricts). Imports nothing from the engine. Evaluates the gates first; if any fails it prints only the gate block, exits 1 and writes nothing. Otherwise prints blocks `4.0a` worked example, `4.0b` gates and reportability, `4.1` headline (E1, E2, G1, G2 per new rule: percentile per book, p, Holm p, detail with null median/SD/5th/95th/edge/MDE/below-equal-above, verdict table with MDE beside every FAIL, secondary statistics, the `-orig` reference rows and their check against T11's/T08's stored percentiles, F2/F4 beside), `4.2` regime weeks and sessions, D-table, trades by kind and cost, regime ledger and which spells carry the difference, comparators (including `cmix_<rule>`), `4.3` R6, `4.4` R1-R7, `4.5` outcome map per window, base and variant plus the windows-agree line, `4.6` power, MDE, sessions invested, OUT-SELL weeks in the draws. Writes `evidence/analysis.log` (default `--out`). The module is also imported by `report.py` (class `Win`, `compute_criteria`, `compute_dtable`, `compute_r6`, `outcome_rows`).
- **`fill_writeup.py`** (fork of T11's) writes section 4 of `T14.md` between `## 4. Results` and `## 5. Findings` from `evidence/analysis.log`, with BEGIN/END markers. It hashes the frozen region exactly as `check_prereg.py` does before and after, compares the bytes in front of the section-4 heading and sections 5-8, and refuses to write on any difference or on misplaced markers. **Not run against the real `T14.md`**; proved on copies in the scratchpad: prefix identical, region hash equal, tail identical, second run replaces in place, a duplicated BEGIN marker is refused.
- **`report.py`** writes `evidence/report.html` (R10 order: answer, data, one backtest end to end per window, headline and verdict table, D-table and regime ledger and comparators, per-book curves of the six rules and the parent, R6, robustness, power, definitions). Every number is `<span class="v" data-k=KEY data-v=RAW ...>`; every string (verdicts, outcome codes, signs, dates, in/out states) is `<span class="s" data-k=KEY ...>`; charts embed their arrays (`lines-data`, `bars-data`) and the hover reads them. Histograms (40 bins) are drawn for the first book only (CAGR and max drawdown of each new rule against its deciding null; R6 delta CAGR), inside `<details>`; the other books' numbers are in the tables.
- **`check_page.py`** shares no code with the others: re-derives every `KEY` from the raw evidence (own percentile, p, Holm, regime counts, ledger, histogram binning, curves) and checks RAW and the displayed TEXT; every date span; every card has a date span and links its formulas; every formula box exists; lines/bars data equal the evidence; hover handles exist; every date written in the text is a date of the evidence or of `T14.md`; the pre-registration hash is on the page. Mutation test (scratchpad): a changed raw value, a changed displayed number, a flipped verdict, a wrong window date, a removed formula box, a changed histogram bin and a typed date were each detected (exit 1). Smoke: 5,116 checks, 0 failures; real W1: 7,169 checks, 0 failures.
- **`rerun_draw.py`** (fork of T11's, uses the engine's `Book`, `simulate`, samplers): `--win w1|w2 --book B --family F1..F5 --id N [--cost] [--span full|r3] [--cash lbes|liq] [--rule] [--gold-id]`; rebuilds the draw, runs all six rules, recomputes CAGR and max drawdown by hand from the NAV, compares every statistic with `draws.csv`, the states with `draw_states.npz`, and (F1/F3, headline cell) the NAV with `draw_curves_20.8.npz` (float64, 1e-12). Tested: W1 F1, W2 F3, W2 F1 `r3`, F5 (equal and different gold id), LIQUIDCASE cell, F4 at 0 bps: all EQUAL.
- **`run.sh`**: `check_approved_data.py`, `check_prereg.py`, the two engine windows in parallel (logs to `logs/step_5_run_w{1,2}.log`, overwriting the current ones), `verify_t14.py --run`, `analyse.py --require-v1`, `fill_writeup.py`, `check_prereg.py`, `report.py`, `check_page.py`, `check_prereg.py`; `set -euo pipefail`; `bash -n` clean. `RUN=name bash tests/T14/run.sh` uses another run directory.

T08's stored file has the 50/50 rule against F1 only, so 50-orig is compared against F1 only; T06's window differs (to 2026-10-22), its regression is the engine's V4(a).
3. **Percentile and p:** as T14.md 2.2; for max drawdown "worse" = deeper (more negative), so a higher value is better for both CAGR and max drawdown. Ties: `np.isclose(rtol=1e-12, atol=0)`. p counts tied draws as at least as good.
4. **Holm:** the family is the window's 16 criteria (4 new rules x E1, E2, G1, G2), per book, p from the percentile's own formula.
5. **MDE:** 2.8 x SD (ddof 1) of the null's statistic, per book (books differ); the verdict table shows the min-max over books beside every FAIL.
6. **Pass with fewer than four books** still uses "at least 3"; the log and the page say so (development runs only).
7. **Outcome map (T14.md 2.4) read mechanically.** "Difference positive in >= 3 books" and "negative in >= 3" are read on the CAGR difference (variant minus original) of the D-table at 20.8 bps, full window, LBES. "R6 paired percentile >= 90" is read as >= 90 in >= 3 of the books on the CAGR contrast, and is printed against F1 and against F3 separately because the map names no null (codes P1/P2/P3/none per null). "E1/E2 pass for a variant where its `-orig` passed" is applied in both windows (the map lists W2): variant verdict, original verdict (E1/E2 of the `-orig` rule, reference only) and the mean percentile change on the common draws are printed. "F1/F2 or F3/F4 disagree" = the criterion's pass verdict (>= 90 in >= 3 books) differs between the deciding null and the one beside it. "The two windows disagree" = the direction class (positive, negative, mixed) differs, or, for positive, the R6 >= 90 flag differs for F1 or F3.
8. **R6 with a zero real difference** (none expected) ranks against the draws' exactly-zero differences (`_rank_zero`). R6 is also printed at 0 and 50 bps inside R1.
9. **Weeks and sessions per regime:** decision j's target is in force from its trade session (decision_idx + 1; j = 0 from session 0) to the next decision's trade session; the last runs to the last session; the regime sessions sum to the window's sessions - 1. Sessions invested (real) = the IN regime's sessions by this rule; recomputed for the F1 draws from `draw_states.npz` (max |difference| from `draws.csv` printed: 0 on smoke and on real W1).
10. **Cost paid** is the engine's `cost_paid` (units of the starting NAV 1), shown as % of the starting NAV.
11. **R3 dates** on tables and charts = the first decision date of `decisions_r3.csv` to the window's last date; W2's R3 is the engine's `r3` (T08's `live`).
12. **Worked example choices:** book = the first book; rule 50-half at 20.8 bps; the entry/exit/in-regime basket change are the first OUT-SELL spell of 50-half that contains a basket change (else the first spell); F1 and F3 draw id 0; ranking for 80-half E1/E2.
