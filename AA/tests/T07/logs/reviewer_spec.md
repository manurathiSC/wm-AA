## The tag rule you are checking (decided by Manu 2026-11-11)
- **cutoff** = the first `snapshot_date` in D21 (expected 2026-04-09).
- **Before the cutoff:** the tag of a stock on date d is the band of its rank on the **latest D20 snapshot with date <= d** (never later; no averaging; the 2026 rows are daily and are used as stored). Rank: among that date's rows with a non-null `mcap`, sorted by `mcap` descending, ties by `quote_id` ascending; rank 1 = largest. Bands: rank 1-100 Large, 101-250 Mid, above 250 "Small and below". Rows with null `isin` or `ticker` are ranked and keep their position; null-`mcap` rows are not ranked.
- **On or after the cutoff:** the latest D21 snapshot with `snapshot_date` <= d: NIFTY 100 -> Large, NIFTY MIDCAP 150 -> Mid, NIFTY SMALLCAP 250 and NIFTY MICROCAP 250 -> Small and below. A stock in none of the four indices uses the rank rule above ("nonmember_rank").
- A stock with no rank on that snapshot reads Small and below and is counted as "unranked" (never silent).
- Identity: found by ISIN, or through D22 by any other ISIN sharing its `quote_id`.
- Only `instrument_class = 'ordinary'` is in D20 already. The CSVs write NULL, empty string and numeric NaN all as an empty cell; read with only the empty string as null (`keep_default_na=False, na_values=[""]`), or "NA"-like values break.
