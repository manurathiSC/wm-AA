# T07 independent verifier: the spec (Step 3)

**Written 2026-11-12 from `T07.md` §2-§3 (frozen) and `logs/evidence_contract.md`.** `AA/analysis/verify_t07.py` is written from this spec by an agent that does **not** read `AA/analysis/t07_engine.py` (if it exists) or `AA/analysis/tag_lookup.py`, and **imports nothing from them, from `approved_data.py` or from any AA analysis module**. It may read `AA/analysis/verify_t06.py` and `verify_t03.py` for style and structure only. Where this spec and T07.md differ, T07.md wins.

## What it is
A re-derivation of the engine's evidence from the raw approved files, with its own code. It exits 0 only if rows were compared and none failed, writes `evidence/<run>/verify_t07.json` with counts per check, and on a deliberately corrupted copy of the evidence it exits non-zero.

## Inputs it may read
Only `APPROVED` rows of `AA/data/APPROVED_DATA.md` (parse the table itself; do not import `check_approved_data.py`): the D17 extended published NAVs, D03 extended Master files, D18 OHLC and `price_corrections.csv`, D19 weight matrices / columns / sources, D05, D09, D12, D11, **D20-D23 under `Historical Data/extended_2026-11-12/` with its own tag lookup** (T07.md §3 "The tag rule"), plus `AA/tests/T06/evidence/headline/{daily_nav,decisions}.csv` for the regression, and the engine's evidence in `AA/tests/T07/evidence/<run>/` (`logs/evidence_contract.md` lists the files). Read the D20-D23 CSVs with only the empty string as null (`keep_default_na=False, na_values=[""]`). Run Python as `python -I` from `AA/`.

## Checks
1. **C-data.** Every `inputs.csv` row is an APPROVED row of the registry with a matching sha256 prefix and a through-date that covers the window end 2026-10-30 (exempt: D19, D05, D12, which end earlier by design).
2. **C-dec.** Re-derive the weekly decisions per book from the D17 calendar (T0 = the book's first session; then the last session of each ISO week; the window ends 2026-10-30) and the D03 Master SIGN rows (latest row on or before the date); compare `decisions.csv` (dates, three SIGN cells, `disagree`).
3. **C-tag (the tag rule, your own implementation).** From D20-D23 implement T07.md §3 "The tag rule": cutoff = first D21 snapshot; on or after it the latest D21 snapshot on or before the date, member band by index; non-members fall back to rank; before the cutoff the rank on the latest D20 snapshot on or before the date (ordinary shares, market cap descending, ties by quote_id, 1-100 Large, 101-250 Mid, above 250 Small and below, rows with a null market cap not ranked); ISINs resolved through quote_id (D22 `isin` and `new_isin`); not found = `Small and below`, `unranked`. Compare with `event_stocks.csv` (`band`, `tag_source`, `tag_snapshot`) for **every row**. Never use a snapshot dated after the information date.
4. **C-events.** Re-derive the events per T07.md §3 step 4 from your own decisions, baskets (D19 listed weights; baskets flagged `csv_only_skipped` in the sources file dropped) and tags: T0; a signal event on the session after a decision date whose dropped set (under the tags read at the last event) differs from the current one; a basket event on the first D17 session on or after a basket's availableDate when the book holds a stock. Compare `events.csv`: `kind`, `trade_date`, `info_date`, `n_held`, `n_dropped`, `dropped_weight`, `sleeve_share_s`, `partial`. Information date = the D17 session before the trade session.
5. **C-target / C-nav.** Re-derive the targets (T07.md §3 step 6: kept stock V x w_i; GOLDBEES and cash V x s / 2 each; every position scaled by k = (V - cost) / V) and re-simulate the rule from the events, with your own simulator, at 0, 20.8 and 50 bps; compare `daily_nav.csv` (`segment`) and `trades.csv`. End NAV within a relative 1e-9. Do the same for `whole_book`, `parent` (always in), `constant_mix`, `sleeve100`, and re-derive `stats.csv` (CAGR, max drawdown, volatility, Ulcer index, days below 10%, longest underwater, Calmar, with years = (sessions - 1) / 252).
6. **C-t06.** With all three bands tied to the single state (IN iff all SIGN BUY) your simulator must equal `AA/tests/T06/evidence/headline/daily_nav.csv` (strategy, same cost) on every shared session up to 2026-10-22 within a relative 1e-12, and the decisions equal T06's `decisions.csv` on every shared decision date. This validates your own simulator against an independent one; do not copy its code.
7. **C-always-in.** Hold every stock (never dropped) at 0 cost: compare with the published NAV (D17) within the G0 tolerance (+/-0.25 pp/yr overall, +/-0.5 pp in every calendar year); compare `g_engine.csv`.
8. **C-draws (structure, every draw).** From `draw_drops.npz` and `event_stocks.csv`: for **every** N4.6 draw of every book, window and event, the dropped subset is inside the held set; its total listed weight is within tau = 0.5 x (the smallest listed weight in the basket) of the rule's dropped weight; at events where the rule drops nothing (or everything) the draw drops nothing (or everything); the event list is the rule's. For **every** N4.8 draw, using `draw_labels.npz`: the number of stocks per label (0 Large, 1 Mid, 2 Small and below) equals the rule's counts n_large, n_mid, n_small at every event, and a stock is dropped in `draw_drops.npz` iff its label's band signal at that event is SELL; and the labels follow from one persistent random score per ISIN (the same ISIN has the same relative order at every event of the draw: within a draw, if stock A outranks stock B at one event where both are held, it does so at every event where both are held). Compare per-draw `mean_dropped_weight` and `n_events` with `draws.csv`.
9. **C-count.** At every event count the allowed N4.6 subsets by brute force over all 2^n subsets (n <= 16) and compare with `count_table.json`; also the rule's own subset is among them (V5c).
10. **C-draw-nav.** Re-simulate with your simulator, from the saved drops, the first 20 and 20 random draws per book and null at 20.8 bps, and compare the end NAV with `draws.csv` and the daily NAV with `draw_curves_20.8.npz` (relative 1e-9).
11. **C-oracle.** Re-derive the V7 oracle choice (T07.md §2: at each event the allowed subset with the lowest sum of listed weight x realised log return from the trade session to the next event's trade session) and its CAGR; compare `controls_oracle.json`.
12. **C-percentile.** Recompute every percentile and p-value of `analysis.log` (if it exists) / of the rule against `draws.csv` ((worse + 0.5 x tied) / draws x 100, ties within a relative 1e-12; p = (1 + at least as good) / (draws + 1)) for C1, C2 and the secondary statistics; recompute C3 (rule minus whole book, after cost, 20.8 bps).
13. **C-pit.** Every decision uses Master rows dated on or before the decision date, every tag uses a snapshot on or before its information date, every trade is on a later session than its decision: count them and report violations (must be 0 out of a count > 0).
14. **C-corrupt.** Make a corrupted copy in scratch space (flip a tag, change a target weight, move a drop outside its allowed set, scale a NAV, delete an event) and require that the relevant checks fail and the script exits non-zero on it.

## Output
`verify_t07.json`: for every check the rows compared, the failures and the worst difference. Exit 0 only if every check compared at least one row and none failed. While no engine evidence exists, test the verifier on a mock evidence set that you build yourself in scratch space from your own simulator (T06's verifier was developed that way), and say so in your log.
