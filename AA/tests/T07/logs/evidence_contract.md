# T07 evidence contract (shared by Steps 2, 3 and 4)

**Written 2026-11-12 from `T07.md` §2-§3 (frozen) and T06's evidence.** The engine (Step 2) writes these files, the verifier (Step 3) and the scripts (Step 4) read them. Where T07.md §1-§3 and this file differ, T07.md wins. Evidence goes to `AA/tests/T07/evidence/<run>/`, `<run>` = `headline` (2,000 draws) or `smoke` (a few draws, one book). Columns not listed are free; listed columns must exist with exactly these names. Dates are ISO `YYYY-MM-DD`. Book names `SCMO_0003`, `SCMO_0007`, `SCMO_0010`, `SCMO_0029` (book_no 0 to 3 in that order). Bands: `Large`, `Mid`, `Small and below`. Band signal: Large = Nifty100, Mid = MC100, Small and below = SC100 (SIGN is `BUY` or `SELL`). Windows: `full`, `live`. Cash: `lbes` (headline) or `liq` (R3).

Calibrated against T06's `AA/tests/T06/evidence/headline/` (same file names and columns where the same file exists).

**Engine CLI** (Step 2 must provide; Step 4's `rerun_draw.py` calls it): `python analysis/t07_engine.py --run <name> [--draws N] [--quick]` writes the evidence; `python analysis/t07_engine.py --rerun --book B --type N4.6|N4.8 --id N --cost C --window full|live [--cash lbes|liq] --out file.json` rebuilds one draw from its id and writes `{"end_nav", "cagr", "max_dd", "drops": [0/1 per row of event_stocks.csv]}`; `--quick` runs one book with few draws for a smoke test.

**Seeds** (T07.md §3 step 11 and 12): N4.6 `numpy.random.default_rng([7, draw_id, book_no])`, one `rng.random()` per event in event order, allowed subsets listed by increasing bitmask over the held stocks in increasing ISIN order, pick index floor(u x count); N4.8 `default_rng([8, draw_id, book_no])`, one score per ISIN the book ever holds in increasing ISIN order; V6 `[9, shift_index, book_no]`.
