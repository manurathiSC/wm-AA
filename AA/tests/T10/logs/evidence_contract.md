# T10 evidence contract (shared by Steps 2, 3 and 4)

**Written 2026-11-12 from `T10.md` §2-§3 (frozen) and T07's contract.** The engine (Step 2) writes these files; the verifier (Step 3) and the scripts (Step 4) read them. Where `T10.md` §1-§3 and this file differ, `T10.md` wins. Evidence goes to `AA/tests/T10/evidence/<run>/`, `<run>` = `headline` or `smoke`. Listed columns must exist with exactly these names; others are free. Dates ISO `YYYY-MM-DD`. Books `SCMO_0003`, `SCMO_0007`, `SCMO_0010`, `SCMO_0029` (book_no 0 to 3 in that order). Bands `Large`, `Mid`, `Small and below`; band signal: Large = Nifty100, Mid = MC100, Small and below = SC100 (SIGN `BUY`/`SELL`). Windows `full` (2019-01-02 → 2026-10-30) and `live` (first session on or after 2021-11-01 → 2026-10-30). Cash `lbes` (headline) or `liq` (R3). **There are no null draws in T10.**

**Engine CLI:** `python analysis/t10_engine.py --run <name> [--quick] [--r4 N]` writes the evidence; `--rerun --book B --id N --out f.json` rebuilds one R4 draw from its id and writes `{"cagr", "diff_vs_switch", "weeks_changed"}`.

**Seeds** (T10.md §2-§3): R4 `numpy.random.default_rng([10, draw_id, book_no])`: for each decision in order, for each held stock in increasing ISIN order whose tag source is `rank` or `nonmember_rank`, two uniforms `u1, u2` in that order; the band is replaced iff `u1 < 0.0793`, by the first of the other two bands (in the order Large, Mid, Small) if `u2 < 0.5`, else by the second. Bootstrap `default_rng([11, resample_id, book_no])`: `n` = the number of daily returns (sessions − 1), `starts = rng.integers(0, n − 19, size = ceil(n / 20))` (one draw of an array), blocks of 20 consecutive daily log returns from each start, concatenated and cut to n, the same indices applied to both series; CAGR of a series = exp(Σ log returns ÷ (n ÷ 252)) − 1; the interval is the 2.5th and 97.5th percentile (`numpy.percentile`, linear) of the 1,000 CAGR differences (rule minus comparator). V5 sample: `numpy.random.default_rng([12, book_no]).choice(n_rows_full_window_decision_stocks_of_the_book, 500, replace=False)` over the book's `window = full` rows of `decision_stocks.csv` in file order.
