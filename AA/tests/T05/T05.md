## 1. Idea and references

**The idea in one sentence.** With the stock filter reviewed once a month during SELL (not every week), keeping the SCMO_0003 stocks that pass a simple technical test (close above a moving average, or a weekly SuperTrend on BUY) and putting only the rest into the 50/50 GOLDBEES and cash sleeve earns more, after cost, than keeping a random set of the same number of stocks drawn at the same monthly cadence.

**Where it came from.** T04 tested the filter every SELL week. Only the 200-day SMA passed the return bar (CAGR percentile 98.3), and the edge was mostly lower turnover: the null drew a fresh random set every week and traded 217 times against the filter's 144 (F-AA-M03); at 0 bps the percentile was 93.7. A monthly review lowers both sides' turnover, because the null now re-draws only at the same review dates, so the turnover gap that confounded T04 shrinks. T05 asks the same question with that confound reduced.

**The decision this will change.** Whether the production rule should run a monthly stock filter during SELL (and by which indicator), or stay fully defensive as T03's rule does.

**What is already known.**

| Ref | What it says | Relationship |
|---|---|---|
| T04 (COMPLETE 2026-11-06) | Weekly filter in SELL: C1 passes for I4 only (98.3), C2 for none, R5 fails (52.4); F-AA-S05 NOT ESTABLISHED; every filter earns 19.6-21.6% against T03's full switch 28.45% | depends on: T05 re-runs T04 with a monthly review cadence and reads the same data, seen |
| F-AA-M03 (T04) | A null that re-draws every period does not hold turnover, and a persistent filter beats it partly for that reason alone | motivates: T05's cadence is the first step to reducing the gap; it is not a full turnover match (§3 contaminants) |
| F-AA-M04 (T04) | A verifier spec paraphrasing an ordered branch was ambiguous | applied: §3 gives every ordered branch and the review rule in full |
| T03 (COMPLETE 2026-11-05) | The three-index switch times SCMO_0003 better than the same spells placed at random: C1 96.0, C2 97.5 (F-AA-S04, PROVISIONAL) | depends on: same regime series |
| T02 (descriptive) | 50-day EMA filter in SELL: 19.9% CAGR against 21.6% for the full AA overlay | contrasts: no null, external data. Seen |

**What this test is NOT asking.**
- Whether the three-index switch times the market (T03 answered that).
- Whether partial equity during SELL beats full defensive. That is a comparator (§3), not a null.
- Whether any of this generalises to SCMO_0007, SCMO_0010 or SCMO_0029. One parent only.
- Whether a monthly cadence is better than a weekly one as a rule. Each cadence is judged against its own null; T04 and T05 are not compared by a test, only side by side.

## 2. Hypothesis and pre-registered criteria

**Written before any T05 engine or verifier code and before any run, 2026-11-06.** What was already known:
- The five indicators and the regime series are T04's, which has been seen in full, with every T04 return, percentile and trade count. The monthly cadence was chosen *because of* T04's turnover finding. This is not out of sample.
- No T05 return, drawdown, selection count, review count or percentile of any kind was computed before this section was written. The review count (about 50 to 60) in the plan is an estimate from the calendar, not a computed number.
- **Expectation, declared:** the turnover gap shrinks but does not vanish (the strategy's kept set is frozen between reviews and the null's too, but they are not the same set at each review). With fewer than 60 reviews and about 10 SELL spells, the most likely result is that I4's after-cost percentile falls below 98 and no indicator passes both C1 and C2. If I4 still passes C1, the 0 bps percentile (R2) decides whether it is selection or turnover.

**Hypotheses** (after cost at 20.8 bps round trip; SCMO_0003 only; one pair per indicator I1 to I5):
- **H1ᵢ, selection.** Indicator Iᵢ's monthly filter keeps stocks that earn more during SELL than a random selection of the same size drawn at the same review dates. Judged on after-cost CAGR. Falsified if C1ᵢ fails.
- **H2ᵢ, protection.** Indicator Iᵢ's monthly filter has a shallower worst fall than a random same-size monthly pick. Judged on maximum drawdown. Falsified if C2ᵢ fails.

**The five indicators** (unchanged from T04; all from the stock's own close prices, point in time):

| # | Indicator | Keep a stock if | Parameters |
|---|---|---|---|
| I1 | 50-day EMA | close > EMA₅₀ | k = 2/51; EMA₀ = mean of the first 50 closes; strict inequality |
| I2 | 200-day EMA | close > EMA₂₀₀ | k = 2/201; EMA₀ = mean of the first 200 closes; strict inequality |
| I3 | 50-day SMA | close > SMA₅₀ | mean of the last 50 closes; strict inequality |
| I4 | 200-day SMA | close > SMA₂₀₀ | mean of the last 200 closes; strict inequality |
| I5 | Weekly SuperTrend | the supertrend is BUY | on the stock's own weekly candles; mul = 2.0, lookback 5 weeks, linearly weighted true range |

**The cadence (what changes from T04).**

| Element | Rule |
|---|---|
| Regime check | weekly, as T04: BUY iff all three Master signals are BUY at the decision date, else SELL |
| Review flag | a weekly decision carries the flag if it is the last decision of its calendar month (by the decision's own date), or if it is the first SELL decision of a SELL spell (a BUY→SELL flip, or decision 0 if SELL). The flag is a property of the decision series; it has effect only when the regime is SELL |
| In SELL, review decision | the indicator is evaluated on that date and the pass set is stored |
| In SELL, non-review decision | nothing is re-evaluated: the stored pass set of the latest flagged decision is used |
| SELL→BUY | immediately the whole basket in force (the BUY switch overrides the monthly cadence); the stored pass set is dropped |
| Basket change in SELL | the stored pass set (all stocks, independent of any basket) is intersected with the new basket's stocks; no fresh indicator evaluation |

**Null: N_sel (selection shuffle at the review dates).**

| Dimension | Randomised / held / not matched | How | Measured in §4 as |
|---|---|---|---|
| which stocks are kept at each review | **randomised** | k stocks drawn uniformly without replacement from the n in the basket in force, using the uniform numbers of the review decision's row | — |
| the review dates | held | the strategy's (same flag series) | — |
| between reviews | held | the null's kept set is frozen too: the same review row of uniform numbers, k for the basket in force | — |
| k, the number kept | held | the indicator's own count at the review decision (its stored pass set intersected with the basket in force) | per draw and SELL decision: kept = k(review, basket) (V3) |
| the regime series | held | the strategy's | — |
| weights of the kept stocks | held | their basket weights, not scaled up; the rest of the weight goes to the sleeve | — |
| BUY-regime behaviour | held | the whole basket at its weights | per draw: BUY targets equal the strategy's (V3) |
| parent rebalances, calendar, sleeve split, cost, execution | held | constant for the run | — |
| the sleeve's return path | **not matched** | different random picks leave different weeks and amounts in the sleeve | null CAGR spread |
| turnover (the number of times the kept set changes) | **not matched, bounded** | both sides now change the kept set only at reviews and on basket changes, but a random set at each review differs from the last more than the filter's does | strategy and null trade counts and cost paid, and the 0 bps percentile (R2), all in §4 |

**Draws.** 2,000 per indicator and cost. Seed `numpy.random.default_rng([5, i, draw_id])` with i = 1…5 for I1…I5 and draw_id = 0…1,999 (salt 5, so T05's draws are independent of T04's); the same draw ids for every cost and sleeve variant. A draw makes one uniform number per stock per decision (`u` of shape J × N); at a review decision j and a basket b the k stocks of b with the smallest `u[j]` are kept. Details in §3.

**Best-of-sweep null (R5).** For each draw_id, take the highest after-cost CAGR among the five indicators' draws of that id. The strategy's best CAGR among I1…I5 is ranked against these 2,000 values with the same percentile rule. Pass mark 98.

**Which null decides.** N_sel, per indicator. R5 and the 0 bps reading (R2) decide the status of any finding, not the per-indicator verdicts.

**Statistic the null is judged on.** After-cost CAGR for H1ᵢ, higher better. Maximum drawdown on daily NAV for H2ᵢ, shallower better.
- **Unit:** one realisation is indicator × cost. The percentile is computed against its own draws.
- **Percentile:** (draws worse + 0.5 × draws tied) ÷ draws × 100. Ties are equal within a relative 1e-12.
- **p-value:** (1 + draws at least as good) ÷ (draws + 1), reported beside the percentile; the pass mark is on the percentile.
- **Secondary statistics**, each against the same draws: volatility of daily returns × √252 (lower better); Ulcer index (lower better); days at least 10% below the running peak (fewer better); longest time under water (shorter better); Calmar = CAGR ÷ |maximum drawdown|.

**Multiplicity.** Five indicators with equal standing at a family-wise α = 0.10, Bonferroni: α/5 = 0.02 each, so the pass mark is the **98th percentile**. 2,000 draws give a resolution of 0.05 points and a smallest p-value of 1/2001; (D + 1) ≥ m ÷ α = 50 is met. Each indicator has two criteria (C1ᵢ, C2ᵢ), the two readings of one test, not further corrected.

**Pre-registered pass criteria** (after cost at 20.8 bps; per indicator):

| # | Criterion | Pass condition |
|---|---|---|
| C1ᵢ | Selection (H1ᵢ) | after-cost CAGR percentile against the N_sel null ≥ 98 |
| C2ᵢ | Protection (H2ᵢ) | maximum-drawdown percentile against the N_sel null ≥ 98 |

Applied to the full window and again to R4's live window before the live percentile is read. (T04 counted every SELL decision; the unit is now the review.)

**Construction, in order.** Every convention below is fixed here; none is left to the engine. Steps 1 to 5 and 8 to 10 are T04's, repeated so the text is self-contained; steps 6, 7, 11 and the review rule in step 5a are T05's.

1. **Calendar.** D17's dates from 2019-01-02 to 2026-10-22, then the D18 sessions after it (2026-10-23 → 2026-11-04, nine sessions). The eight D18 sessions D17 lacks are never read after 2019-01-02 (F-AA-D15), for prices, indicators and weekly candles. Before 2019-01-02 all D18 dates are used (indicator history only).
2. **Decision dates.** T0 = 2019-01-02, then the last session of each ISO week after T0. T0 is the window's base. The decision at 2026-11-04 is not traded.
3. **Regime at decision date d.** The latest Master row of each of the three indices dated on or before d; BUY iff all three SIGN are BUY, else SELL. The decision series must equal T04's headline `decisions.csv` on every date they share (checked and printed, not a gate).
4. **Baskets.** A basket takes effect on the first calendar session on or after its availableDate; baskets flagged `csv_only_skipped` are dropped; its weights are normalised to sum 1 over the whole basket. A kept stock keeps its normalised weight; weights are not scaled up when stocks are dropped.
5. **Indicator values.** From each stock's own bars (never forward-filled): `close` is the last close on or before the decision date d, taken only if that bar is at most 7 calendar days before d; otherwise the stock is excluded. The EMA of a stock at bar m ≥ N (N = 50 or 200) starts at the mean of its first N closes and then EMA = k × close + (1 − k) × previous; the SMA is the mean of the last N closes. A stock with fewer than N bars, or (I5) with fewer than 5 weekly bars, cannot be computed and is **excluded** (fails the filter). Strict inequality for I1 to I4. I5: weekly candles are ISO weeks (Monday to Sunday) of the stock's own bars, high = max, low = min, close = last; true range = max(high − low, |high − previous close|, |low − previous close|) (the first candle: high − low); weighted ATR = Σ (weight × TR) over the last 5 candles, weights 1…5 divided by 15; centre = (high + low) / 2; BUB/BLB = centre ± 2 × ATR; the final bands and the trend ratchet follow `analysis/supertrend.py` read in its **ordered** branches exactly as written there (F-AA-M04: the order of the branches is part of the rule), written out in the engine, not imported; BUY iff the supertrend sits on the final lower band; not yet defined or on neither band is excluded. The candle read at d is the candle containing the stock's last bar on or before d.
   - **5a. The review flag.** Let D be the decisions j = 0…J−1 with dates d_j and regime s_j (1 = BUY, 0 = SELL). `review[j]` = True iff (a) j is the last decision whose date falls in the calendar month (year, month) of d_j, or (b) s_j = SELL and (j = 0 or s_{j−1} = BUY). The flag is computed for every decision in every regime; it has effect only where s_j = SELL. `n_reviews` = the number of j with `review[j]` and s_j = SELL. The last decision of the window (2026-11-04) is the last of its month and carries the flag, but it is not traded, so it influences no NAV; it is counted in `review_mask_count` and excluded from `n_reviews`'s trade-relevant statistics (the engine prints both).
   - **5b. The stored review pass set.** For a SELL decision j let r(j) = the largest j′ ≤ j with `review[j′]` (it lies in j's SELL spell, because the first SELL decision of every spell is flagged). The stored pass set P(j) = the stocks, of all 197 ever held and independent of any basket, that pass the indicator at decision r(j) under step 5. At a review decision r(j) = j.
6. **Selection in SELL.** At a SELL decision j, and for the basket b in force at the session of the target, the kept set is P(j) ∩ b. Its count k and the basket size n are logged (`selections.csv`, with `review_j` = r(j)). Stocks not kept have their weight in the sleeve: 50% GOLDBEES and 50% LBES cash (R1: 100% GOLDBEES). If k = 0 the whole book is in the sleeve; if k = n the book equals the BUY book. Both are counted and reported. A stock that enters the basket after r(j) is kept if it passed at r(j), because P(j) is a function of the stock's prices on the review date alone.
7. **Target.** At any session t, the book's target is a vector of stock weights x(t) plus the sleeve. In BUY: x = the basket in force at t. In SELL: x = the basket in force at t, with stocks outside the kept set set to zero. The decision in force at t is the latest decision whose trade session is on or before t (T0's decision before the first trade). The kept set at t is P(j) ∩ b for that decision j and the basket b in force at t, so a parent rebalance during SELL re-applies the *stored* pass set to the new basket; it never re-evaluates the indicator.
8. **Trades.** On the next calendar session after each decision, and on each session where a new basket takes effect, compute x(t). **A trade happens if and only if x(t) differs from the last target** (exact comparison). The last target at T0 is the T0 decision's own target. When a trade happens, at that session's fills, with V = value of all holdings at fill prices, every line is traded to its target: stock i to x_i × V, GOLDBEES and cash to (1 − Σx) × V × share (50/50; R1 100/0); traded = Σ |target − held| over every line; cost = traded × cost_bps ÷ 2 ÷ 10,000; every target is then scaled by (V − cost) ÷ V. Fills: stocks OHLC4 of the Eikon bar (close if open, high or low is blank; the last close if the stock has no bar that session), GOLDBEES de-spiked OHLC4, LBES level. No trade happens at a session where x(t) equals the last target, so a SELL week with no change in the kept set costs nothing and the kept stocks drift. Between reviews the kept set changes only on a basket change, so most SELL weeks are no-trade.
9. **Initial position at T0 close**, NAV 1.000, no cost, in every realisation including the nulls: the basket in force at T0, as drifted since its availableDate (units from OHLC4 on the first D18 session on or after it, scaled to value 1 at T0's close), with the stocks outside T0's kept set sold at T0's close into the sleeve (50/50). In BUY the kept set is the whole basket. If T0 is SELL, decision 0 is a review (5a (b)).
10. **NAV, statistics.** Daily NAV = Σ units × close + GOLDBEES units × close + LBES units × level; no sale at the end. years = (sessions − 1) ÷ 252; CAGR = NAV_end^(1/years) − 1; maximum drawdown, Ulcer index, days at least 10% below the running peak, longest time under water, volatility, Calmar as in T03 and T04.
11. **Null draws (N_sel).** For draw_id and indicator i, `rng = default_rng([5, i, draw_id])`, `u = rng.random((J, N))` with J the number of decisions and N the number of stocks ever held (column order as in the D19 weight matrix). At a SELL decision j and a basket b the draw keeps the k_{r(j)}(b) stocks of b with the smallest `u[r(j)]` (stable sort on ties), where k_{r(j)}(b) = |P(j) ∩ b| is the indicator's count for that basket, so the same uniform row serves every non-review SELL week and every parent rebalance of the spell. **Rows are drawn at the review date, not at the current decision (`u[r(j)]`, never `u[j]`).** Everything else (targets, trades, costs) goes through steps 7 to 10 unchanged. The live window's `u` is drawn with the same seed over its own J.
12. **Live window (R4).** A separate book starting 2021-11-01 with its own decision series (its first decision is its T0), its own review flags by 5a (so if its T0 is SELL it is a review), its own stored pass sets and its own `u` of shape J_live × N. Nothing is carried over from before 2021-11-01.
13. **Percentile, MDE.** Percentiles as in §2. After the run, the MDE for C1ᵢ at 80% power is (z₀.₉₈ + 0.84) × sd_null = 2.894 × the SD of after-cost CAGR across the draws, and the same for maximum drawdown, printed beside every FAIL. **Disclosed:** these numbers did not exist when this section was written. The effective independent unit is the SELL spell (10 to 2026-11, T04 §4.0), not the review.
14. **Comparators** (benchmarks, not nulls; same calendar, cost and T0): hold the parent (decision fixed at IN; each cost) and the published NAV rebased; the full AA switch (k = 0 on every SELL decision); for each indicator, the constant mix at the average equity share f (the mean over decision weeks of Σx, BUY = 1) held as f × the basket and (1 − f)/2 each in GOLDBEES and cash, rebalanced on the next session after every decision date and at every basket change; SCMO_0042's published NAV rebased (descriptive, 2021-11-01 → 2026-08-21 only).
15. **R5.** For each draw_id d, the best of the five indicators' after-cost CAGRs of draw d. The strategy's best CAGR of the five is ranked against these 2,000 (the same draw id is the shared seed).

**Evidence format.** `decisions.csv` (j, decision_date, trade_session, state, basket, review), `indicators.csv`, `selections.csv` (j, decision_date, indicator, stock_col, selected, k, review_j), `trades.csv`, `daily_nav.csv`, `stats.csv` (with `n_reviews`), `draws.csv`, `g_engine.csv`, `audit.json` (with `review_mask_count`), `inputs.csv`, as in `PLAN.md`.

**How the test works, in plain words.**

- **The series.** The book's NAV is built every day from the stocks of SCMO_0003's basket. Every week the three index signals are read. On BUY the book holds the whole basket. On SELL, the first week of the spell and then once a month (the last weekly decision of each calendar month), it looks at each stock in the basket: if the stock passes the indicator it is kept at its normal weight, otherwise its share is moved into half GOLDBEES and half cash. Between those reviews the list of passers is frozen: no stock is added or dropped for how it moved in the meantime. A parent rebalance (a new basket) changes only which of the frozen passers are in the basket. When the signal flips back to BUY the book goes straight back to the whole basket. *[the real review dates, signals, selections and NAV are printed in §4.0a]*
- **One decision.** On a SELL review Friday with, say, 11 stocks, 4 pass the test: those four stay, and the weight of the other seven goes to GOLDBEES and cash. The trade is on the next session at each instrument's (open + high + low + close) ÷ 4, paying 10.4 bps on every rupee traded. The three or four Fridays after it are no-trade weeks unless a new basket arrives. *[one real review is printed in §4.0a]*
- **One null draw.** On the same review Friday the draw also keeps 4 stocks, chosen at random from the 11, using that Friday's row of random numbers, and keeps the same 4 (those still in the basket) until the next review, as the strategy keeps its 4. 2,000 such draws, with the same random numbers reused across costs. *[the same Friday's real and random pick are printed in §4.0a]*
- **The ranking.** The indicator's CAGR is placed among the 2,000 draws' CAGRs: the percentile is the share of draws it beats (ties half). 98 or more is a pass for that indicator. A pass counts as selection only if it also holds at 0 bps.
- **The comparators.** The full AA switch shows what no stock-picking in SELL earns. The constant mix holds the same average equity share in all weeks: it shows how much of any gain is only more equity exposure.

**Point-in-time rule.** A decision at d reads Master rows dated at or before d and bars dated at or before d (the engine asserts both and counts them). A stored pass set used on a later date is the review date's own, evaluated on bars up to that review date. A trade is on a session after d, except a parent rebalance, which is on its availableDate session and uses the stored pass set of the decision in force. Master rows before 2021-11 are a backfill by the production code, not signals traded at the time (disclosed, not corrected).

**What the null controls for, and what it does not.** It controls for how many stocks are kept at each review, the review dates, and so for the amount of equity exposure and the weeks it is held. It does not control for which weeks the sleeve is held, for stock-specific effects such as survivorship in the basket, nor fully for turnover: at a review a random set is unrelated to the last one, while a moving-average filter's passers overlap heavily month to month, so the null still trades somewhat more. §4 reports the trade counts and R2 at 0 bps. With baskets of 5 to 15 stocks, when k is near n there are few distinct picks; §4 reports the reviews with 1 ≤ k < n.

## 5. Findings

### F-AA-S06 — With the stock filter reviewed monthly during SELL, no indicator keeps stocks better than a random same-size pick drawn at the same monthly cadence, on return or on drawdown. SCMO_0003, 2019 → 2026-11, after 20.8 bps

**Status:** NOT ESTABLISHED (no criterion passes). All gates V1–V5 pass.
**Evidence:** `evidence/headline/` (`draws.csv`, `stats.csv`, `audit.json`, `verify_t05.json`), `analysis.log`, §4.1, §4.4 and the robustness table above.
**Claim:** against 2,000 random same-size monthly selections, at the pre-registered 98th percentile, C1 fails for all five indicators (CAGR percentile I1 28.0, I2 65.0, I3 5.1, I4 67.8, I5 29.8) and C2 fails for all five (max-drawdown percentile 18.7, 62.7, 11.3, 42.5, 58.9). The best-of-sweep R5 ranks the best indicator (I2, 19.94%) at the 10.3rd percentile of random best-of-five sweeps (p = 0.8971). No indicator passes in the live window (R4: best C1 71.2, I4), at 0 or 50 bps (R2: at most 72.5), with a 100% GOLDBEES sleeve (R1) or with LIQUIDCASE cash (R3).
**What the data say beside the null (descriptive):**
- **Strategy against null mean.** I2 +0.62 pp and I4 +0.69 pp, I1 −0.93, I3 −2.36, I5 −0.85. The smallest edge the test could see at 80% power is 4.3 to 4.9 pp of CAGR and 7.9 to 9.0 pp of worst fall (§4.3), so edges of the size seen here are far below what this test can detect.
- **Against the alternative.** After cost, T03's full defensive switch earns 28.45% with a worst fall of −18.4%; the five monthly filters earn 17.4% to 19.9% with falls of −32.1% to −35.0%; holding the parent earns 16.66% with −46.3%. Keeping any stocks in SELL gave up 8.5 to 11 pp a year here. The constant mix at I4's average equity share (0.807) earns 15.44% and falls −37.7%.
- **Against T04 (weekly), side by side and not tested.** Every strategy CAGR is lower monthly than weekly (I4 21.48 → 19.75, I5 21.61 → 17.99, I3 20.24 → 17.38), and the null's mean is higher (I4 18.19 → 19.05). T04's one pass (I4, percentile 98.3) is 67.8 here. Cadence and sample are not separated by this design, so this is a reading of the table, not a result.
**Falsified by:** a pre-registered rerun on decisions that were not seen, or on another parent, that clears the 98th percentile with the 0 bps percentile also at or above 98, or an edge larger than the MDE in §4.3. With 10 SELL spells (56 reviews) the effective sample is small.
**Cross-check:** `python tests/T05/analyse.py`; `python analysis/verify_t05.py`.

### F-AA-M05 — Giving the null the strategy's review cadence removes most of the turnover confound that T04 had (F-AA-M03), at the price of a wider null

**Status:** OBSERVED (T05 against T04, one parent).
**Evidence:** §4.1 "What the null does not hold" and the T04-beside-T05 table.
**Claim:** when the null re-draws only at the strategy's review dates and freezes its set between them, the null's mean trades are 1.00 to 1.10 times the strategy's (T04: 1.1 to 2.1 times: 231 / 208, 210 / 151, 227 / 206, 217 / 144, 226 / 110). The gap between each indicator's after-cost percentile and its 0 bps percentile falls from 4.6 to 28.1 points (T04) to 0.5 to 4.3 points (T05), so the after-cost and 0 bps readings now agree. The null's CAGR SD rises from 1.34–1.50 pp to 1.49–1.68 pp and the MDE from 3.9–4.3 to 4.3–4.9 pp, because each draw is a sum over fewer random picks.
**Consequence for design:** a selection test whose null holds the strategy's decision cadence needs no turnover correction, and its 0 bps percentile can be read as a check, not as a separate result. **Falsified by:** none. **Cross-check:** `tests/T05/analysis.log`, §4.1 and §4.3.

## 6. What this does not establish

**Tested and inconclusive:** whether a monthly filter selects better than random by an edge smaller than about 4.3 to 4.9 pp of CAGR (§4.3). The strategy's edge over the null mean (−2.4 to +0.7 pp) is inside that band for every indicator.
**Not tested:** the other three parents; other indicators, parameters or review cadences (quarterly, forced-only); filters on fundamentals or volume; partial equity sized by a rule rather than by stock; the production 80/20 gold-timed sleeve; any decisions not seen before this test; spot checks of D17 and D18 against a public source (the data review is DRAFT); the source of the cash file (F-AA-D09).
**Not claimed:** that the monthly cadence is worse than the weekly cadence (the two are not compared by a test and share the same seen sample); that T03's full switch is the best rule possible. It is the best of the rules compared here, on a window both were seen on.
